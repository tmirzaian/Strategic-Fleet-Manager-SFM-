# Fonts — not populated

This directory exists to reserve the production location for a future
approved typeface. **No font files are stored here**, and none should be
added until licensing is explicitly approved by the Chief Architect —
web font licensing is per-domain/per-use and is not implied by any other
asset approval.

Strategic Fleet Manager currently uses system/Tailwind default font
stacks. When a licensed font is approved, document its license terms and
permitted use directly alongside the font files in this directory.

# Audio (future)

No audio ships with this mission — this directory establishes the
production location ahead of a future audio mission.

- `quartermaster/` — future Quartermaster voice/response audio. Building
  this directory is not the same as implementing Quartermaster voice
  playback; no player is wired up by this mission.
- `ui/` — future interface sound effects (confirmations, alerts).

## Format

WAV master file alongside a compressed runtime format (e.g. WebM/Opus or
MP3) once real assets exist — document the exact runtime format choice
next to the first real asset, not here in advance.

# Privacy

Strategic Fleet Manager (SFM) is local-first software. This document
describes what data the app handles today, during Beta.

## No analytics or telemetry

SFM does not currently contain analytics or telemetry of any kind. Nothing
about how you use the app is measured, recorded, or reported anywhere.

## No data transmission

SFM does not transmit your fleet, inventory, loadout, or usage data
anywhere. There is no backend server for the app itself, and no account to
sign in to.

## Local storage only

Your fleet, ships, loadouts, and inventory are stored entirely in your
browser's local storage, on your own device. This data never leaves your
browser unless you explicitly export or share it yourself.

## No account required

Strategic Fleet Manager does not require — and does not currently offer —
any account, sign-in, or cloud identity.

## External image requests

Some ship imagery is sourced from external URLs (for example, official RSI
media). When SFM displays one of these images, your browser will make a
request to that external host to fetch it, the same as any web page
displaying a remote image. No fleet, inventory, or usage data is included
in these requests.

## Future telemetry

If telemetry is ever introduced in a future release, it will be optional
(opt-in), clearly documented, and will never include your fleet or
inventory data.
